Follow the **[contributor quick start](/developers/contributing/#quick-start)** for the complete, current instructions.

It covers the required Xcode toolchain, automatic GhosttyKit and tool downloads, optional local signing, and building **OmniWM Dev** with separate settings and saved state. You can rebuild your changes and switch back to your normal installation without replacing it.

The same guide includes [everyday commands](/developers/contributing/#everyday-commands), [verification](/developers/contributing/#verification), and [troubleshooting](/developers/contributing/#troubleshooting). Build requirements can be newer than OmniWM's runtime requirements; check the guide before installing Xcode.

For a normal installation without compiling, use the [installation guide](/guides/install/).

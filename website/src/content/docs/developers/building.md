Follow the **[contributor quick start](https://github.com/BarutSRB/OmniWM/blob/main/CONTRIBUTING.md#quick-start)** for the complete, current instructions.

It covers the required Xcode toolchain, automatic GhosttyKit and tool downloads, optional local signing, and building **OmniWM Dev** with separate settings and saved state. You can rebuild your changes and switch back to your normal installation without replacing it.

The same guide includes [everyday commands](https://github.com/BarutSRB/OmniWM/blob/main/CONTRIBUTING.md#everyday-commands), [verification](https://github.com/BarutSRB/OmniWM/blob/main/CONTRIBUTING.md#verification), and [troubleshooting](https://github.com/BarutSRB/OmniWM/blob/main/CONTRIBUTING.md#troubleshooting). Build requirements can be newer than OmniWM's runtime requirements; check the guide before installing Xcode.

For a normal installation without compiling, use the [installation guide](/guides/install/).
